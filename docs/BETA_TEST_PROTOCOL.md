# Mingmaben AI V1 Beta Test Protocol

## Purpose

The public beta does not attempt to prove Mingmaben true. It tests whether an AI-driven whole-form reading can be made stable, auditable, and meaningfully richer than the former deterministic rule engine without rewriting itself after later facts are known.

## Core discipline

1. Freeze the first successful canonical reading.
2. Reading and Evidence are views of the same frozen result.
3. Feedback never mutates a reading.
4. Known reality is not supplied to the initial decoder.
5. Later reality may be compared only after the frozen result exists.
6. A weak case is allowed to return: `No stable whole-form mechanism emerged / 尚未形成稳定整体机制`.
7. Structural evidence strength is not truth confidence.

## Initial fixtures

- Geometry known-reality statement.
- Astronomy known-reality statement.
- Known-false water-bottle existence statement.
- Chinese relationship-space statement.
- Deliberately low-signal sentence.

The expected assertion is method discipline and frozen stability, not a hard-coded semantic conclusion.

## Public evaluation

For each frozen result, collect only one of:

- Correct / 准
- Partly / 部分准
- Wrong / 不准

The original frozen result remains unchanged regardless of feedback.
